THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

CodeBrix.Platform.Fonts.RobotoMono is a CodeBrix-family redistribution of the
Roboto Mono monospace font family, packaged as a .NET 10 NuGet library. Roboto
Mono covers the Latin, modern Greek and Cyrillic scripts but not polytonic
Greek, Armenian or Georgian, so this package additionally bundles three
companion families that supply that coverage. The package therefore
incorporates four pieces of third-party material:

  1. The Roboto Mono font family (SIL OFL 1.1) — the primary text face.
  2. The Noto Sans Mono font family (SIL OFL 1.1) — the polytonic-Greek
     companion.
  3. The Iosevka font family (SIL OFL 1.1) — the Armenian companion.
  4. The Noto Sans Georgian font family (SIL OFL 1.1) — the Georgian companion.

The CodeBrix-authored parts of this package — the `.csproj`, the
buildTransitive `.targets` file, the `.ttf.manifest` JSON files, the
`CODEBRIX-DEVELOP.json` descriptor, the `.uprimarker` marker, the
documentation, and the packaging metadata — are original to the CodeBrix family
and contain no third-party source code. They are released, together with the
bundled font files, under the SIL Open Font License, Version 1.1, the same
license as the fonts. The full license text is bundled with this repository
three times at the repository root — `OFL-Roboto.txt`, `OFL-Noto.txt` and
`OFL-Iosevka.txt`, one per upstream font project, identical in license body and
differing only in their copyright headers — and the same three files are
packaged inside the produced NuGet.

     - src/CodeBrix.Platform.Fonts.RobotoMono/Fonts/NotoSansMono-Bold.ttf

     - src/CodeBrix.Platform.Fonts.RobotoMono/Fonts/NotoSansMono-SemiBold.ttf

   Modifications made during redistribution:
     - Only the six weights Light (300) through ExtraBold (800) are shipped as
       static instances, in the Normal stretch. The upstream Thin (100),
       ExtraLight (200) and Black (900) weights, and the Condensed,
       SemiCondensed and ExtraCondensed stretches, are not included. (All
       remain reachable through the bundled variable font, which carries both
       the weight and width axes.) Upstream publishes no italic face for this
       family, so italic text in the scripts it serves renders upright.
     - The upstream variable font `NotoSansMono-VariableFont_wdth,wght.ttf`
       was renamed to `NotoSansMono.ttf`. No `.ttf` binary content was altered.

3. Iosevka Font Family (Armenian companion)
   ----------------------------------------
   Project URL:    https://github.com/be5invis/Iosevka
   Designer:       Renzhi Li (aka. Belleve Invis)
   Version:        34.4.0
   Copyright:      Copyright (c) 2015-2026, Renzhi Li
                   (aka. Belleve Invis, belleve@typeof.net)
   License:        SIL Open Font License, Version 1.1

   Note on naming: the Iosevka copyright statement declares NO Reserved Font
   Name, so SIL OFL 1.1 condition 3 does not apply to this family. The `.ttf`
   files are redistributed bit-for-bit unmodified; the renames listed below
   change file names only, and the name tables inside the fonts are untouched.

   Why it is bundled: Roboto Mono and Noto Sans Mono do not cover the Armenian
   script, and neither Roboto nor Noto publishes a monospace Armenian face.
   Iosevka is a monospace family with full Armenian coverage. The Extended
   width grade is shipped because its 0.6 em character advance matches Roboto
   Mono and Noto Sans Mono exactly (Iosevka's default grade is 0.5 em), so
   Armenian text keeps the character grid.

   Files redistributed from this upstream project (binary `.ttf` files), taken
   from the release archive `PkgTTF-Unhinted-Iosevka-34.4.0.zip` at
   https://github.com/be5invis/Iosevka/releases/tag/v34.4.0 and renamed
   file-by-file as follows:

     - Iosevka-Extended.ttf          -> Fonts/Iosevka.ttf
     - Iosevka-ExtendedLight.ttf     -> Fonts/Iosevka-Light.ttf
     - Iosevka-ExtendedMedium.ttf    -> Fonts/Iosevka-Medium.ttf
     - Iosevka-ExtendedSemiBold.ttf  -> Fonts/Iosevka-SemiBold.ttf
     - Iosevka-ExtendedBold.ttf      -> Fonts/Iosevka-Bold.ttf
     - Iosevka-ExtendedExtraBold.ttf -> Fonts/Iosevka-ExtraBold.ttf

   Modifications made during redistribution:
     - Only six of upstream's 54 faces are shipped: the Extended width grade in
       the six weights Light (300) through ExtraBold (800), upright only.
       Iosevka does publish italic and oblique faces, but this companion exists
       only to supply the Armenian script and ships upright-only like the other
       companions.
     - The UNHINTED upstream builds are used. CodeBrix.Platform renders text
       through Skia, which does not execute TrueType hinting instructions, so
       the hinted builds would add roughly forty percent to every file's size
       without changing rendering.
     - Iosevka publishes no variable-font `.ttf` (its releases carry static
       TTF/TTC and webfont formats only), so the dash-free `Iosevka.ttf` — the
       slot the sibling packages fill with a variable font — is the static
       Extended-Regular instance, and the manifest's weight-400 entry points at
       it directly rather than at a duplicate `Iosevka-Regular.ttf`.
     - No `.ttf` binary content was altered.
